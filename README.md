# kiswahili3

## Live preview in VS Code

1. Open this folder in VS Code.
2. Choose **Terminal → Run Task → Start live textbook preview**.
3. Open [http://localhost:8000](http://localhost:8000) in your browser.

The page refreshes automatically whenever you save an HTML, CSS, JavaScript,
JSON, image, or XML file. Stop the preview with `Ctrl+C` in the VS Code terminal.
